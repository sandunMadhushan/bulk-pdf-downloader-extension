# Privacy Policy for Bulk PDF Downloader

_Last updated: September 13, 2026_

Bulk PDF Downloader ("the extension") is a browser extension that scans the current web page (or a Google Classroom / Moodle course page) for links to PDF files and lets you select and download the ones you want.

## Data collection

Bulk PDF Downloader does **not** collect, transmit, sell, or share any personal data, browsing history, or website content with the developer or any third party. The extension does not use analytics, tracking, or remote servers.

All processing — scanning the page for PDF links, letting you choose which ones to download, and (optionally) bundling them into a zip file — happens entirely locally in your browser.

## Permissions

| Permission | Why it's needed |
|---|---|
| `activeTab` | Read the content of the tab you're currently viewing when you click the extension icon. |
| `scripting` | Inject a script into the active tab to find PDF links on the page. |
| `downloads` | Save the PDF files you select to your computer. |
| `storage` | Save your preferences locally in your browser between sessions. Nothing leaves your device. |
| `offscreen` | Assemble selected PDFs into a single zip file in the background. |
| Host permission for `classroom.google.com` | Detect PDF/document links on Google Classroom course pages, which load content dynamically. |

## Third parties

The extension does not integrate with any third-party analytics, advertising, or data-collection service.
